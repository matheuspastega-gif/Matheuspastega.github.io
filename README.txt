MVKL — SITE NOVO

1. Entre no repositório Matheuspastega.github.io no GitHub.
2. Abra os arquivos do site.
3. Substitua index.html, style.css e script.js pelos arquivos desta pasta.
4. Envie a pasta images inteira, mantendo os nomes dos arquivos.
5. Faça o commit das alterações na branch main.
6. Aguarde o GitHub Pages publicar.

O domínio mvkl.com.br e o DNS não precisam ser configurados novamente.
